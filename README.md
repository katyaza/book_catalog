# Book Catalog

Приложение для работы с каталогом книг и авторов.

## Реализовано

* просмотр книг и авторов
* поиск и фильтрация книг
* просмотр книги и информации об авторе
* добавление, редактирование и удаление книг
* авторизация
* отчёт ТОП-10 авторов за выбранный год
* подписка на новые книги автора
* тестовые SMS-уведомления при добавлении новой книги

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить проект:

```bash
npm run dev
```

Для SMS-уведомлений отдельно запустить:

```bash
node server/sms.js
```

API-ключ SMSPILOT хранится в `.env`.

## Стек

Vue 3, TypeScript, Pinia, Vue Router, Axios, Less, Vite.
